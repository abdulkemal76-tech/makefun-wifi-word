An entry for the make.fun bounty [One Word for Your Wi-Fi](https://make.fun/bounty/u-tuan-muda-one-word-for-your-wi-fi-a1b4fd72): a program that writes one word describing the entrant's Wi-Fi — the funniest and most accurate one — to `/output/entry.txt`. The winning word becomes the sponsor's network name.

## Run

```sh
python3 -P -s main.py
cat /output/entry.txt
```

## The word

> Liar

Home Wi-Fi's most universal lived truth is not that it is slow — it is that it lies: full bars, "Connected", and nothing loads. The network says one thing and does another, to your face, every day.
